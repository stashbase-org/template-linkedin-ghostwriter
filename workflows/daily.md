# Log My Day

When I tell you what I did today, what I've been working on lately, or an unfinished thought about my work, save it to my inbox and record what's new about me and my work. Do both in one go, including when the conversation comes straight from setup. I don't need to turn it into a post idea first.

## Save it

My inbox is the `inbox/` folder: one file per day, named `YYYY-MM-DD.md`, and [index.md](../inbox/index.md) listing the days, newest first. Save what I tell you to today's file, and create it if it isn't there yet. If today's file already exists, add to the end of it. If I'm talking about an earlier day, like yesterday, use that day's file instead. If I say only "recently" or "lately", use today's file as the day I told you and preserve that wording; don't invent when the work happened.

```markdown
# Tuesday, November 3, 2026

- One thing that happened.
- Another thing.
```

* One line per thing that happened.
* Write it in first person, close to how I said it. Keep the details: names, numbers, what someone said, what broke, how I felt. Tidy the wording, but don't trim details or add anything I didn't say.

Save what I gave you without asking follow-up questions first. Save each later answer in its turn too, appending to the relevant day without duplicating or rewriting what was already recorded.

Then update [index.md](../inbox/index.md): for a new day, add a line at the top of the list; for a day that's already there, rewrite its sentence to cover what's new.

```markdown
- [Tuesday, November 3, 2026](2026-11-03.md): The whole day in one short sentence.
```

## Days I write myself

I can also write a day straight into `inbox/`. A day file that isn't in [index.md](../inbox/index.md) is one I wrote myself: add it to the index, record what's new from it as below, and tell me in a line. Don't change what I wrote.

## Record what's new

Then record what's new about me or my work, as in [AGENTS.md](../AGENTS.md#record-what-i-tell-you): background and voice in `context/profile.md`, explicit standing instructions in AGENTS.md, and project facts in `context/work/`. The inbox keeps what I said that day; my work notes keep where things stand now. You organize and update these files; don't ask me to fill them in.

## Reply

Tell me briefly that it's saved. If one detail would help us understand the work, you may ask one natural follow-up after saving, for example "What made you add that feature?" Skip it if I've already explained or only want to log the day; don't turn this into a questionnaire. The answer gets the same immediate saving treatment.

If something in it would make a good post, say so in one more sentence, and add it to my ideas only if I say so. When I ask for angles, switch to [idea.md](idea.md#when-i-ask-what-to-post) and suggest short outlines from the saved material.

End with one short saved-file line per changed file, using clickable links to the day, inbox index, and any profile, instruction, or work-note changes, as in [AGENTS.md](../AGENTS.md#keeping-my-files).
